## AutomaticImageSize

```
AutomaticImageSize
```

> an option of `Graphics3D` (whether the picture's size follows its contents).

Symja recognises `AutomaticImageSize` as the built-in `System` symbol it is in the Wolfram Language, so a package or a front end that writes it - the WLJS notebook's graphics do - reads the same symbol, but Symja does not act on it.
