## ControllerMethod

```
ControllerMethod
```

> an option of `Graphics3D` and of controls (how a controller device moves the view).

Symja recognises `ControllerMethod` as the built-in `System` symbol it is in the Wolfram Language, so a package or a front end that writes it - the WLJS notebook's graphics do - reads the same symbol, but Symja does not act on it.
