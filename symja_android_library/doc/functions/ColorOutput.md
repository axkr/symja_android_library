## ColorOutput

```
ColorOutput
```

> an option of `Graphics` and `Graphics3D` (the colour model a picture is rendered in).

Symja recognises `ColorOutput` as the built-in `System` symbol it is in the Wolfram Language, so a package or a front end that writes it - the WLJS notebook's graphics do - reads the same symbol, but Symja does not act on it.
