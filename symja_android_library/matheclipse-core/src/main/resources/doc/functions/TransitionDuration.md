## TransitionDuration

```
TransitionDuration
```

> an option for `PaneSelector` giving how long a transition effect lasts, in seconds (Wolfram Language 9.0).

Symja recognises `TransitionDuration` as a built-in `System` symbol, so a package or a front end that writes it - the WLJS notebook's graphics code does - refers to that symbol rather than creating one in its own context. Symja does not act on it.

The WLJS notebook also reads it as an option of `Graphics`.
