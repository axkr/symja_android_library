## HankelH2

``` 
HankelH2(n, x)
```

> returns Hankel function of the second kind.

### Examples

```
>> HankelH2(0, 1.5)
0.511828+I*(-0.382449)

>> HankelH2(1, 2.0+I)
1.39003+I*(-0.0636173)
```
