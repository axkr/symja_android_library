## LatticeReduce

```
LatticeReduce(matrix)
```

> gives a reduced basis for the lattice which is generated by the rows of `matrix`.

The reduction uses the Lenstra-Lenstra-Lovász algorithm with the reduction parameter `3/4`, in
exact integer arithmetic. The rows of `matrix` must be integers or rational numbers.

Rows which are zero or linearly dependent on the other rows don't contribute to the lattice, so the
result can contain fewer rows than the input.

See
* [Wikipedia - Lenstra-Lenstra-Lovász lattice basis reduction algorithm](https://en.wikipedia.org/wiki/Lenstra%E2%80%93Lenstra%E2%80%93Lov%C3%A1sz_lattice_basis_reduction_algorithm)
* [Wikipedia - Lattice reduction](https://en.wikipedia.org/wiki/Lattice_reduction)

### Examples

```
>> LatticeReduce({{1,2},{3,4}})
{{1,0},
 {0,2}}

>> LatticeReduce({{1,1,1},{-1,0,2},{3,5,6}})
{{0,1,0},
 {1,0,1},
 {-1,0,2}}
```

The reduced basis generates the same lattice, so the determinant is preserved up to the sign:

```
>> Det(LatticeReduce({{201,37},{1648,297}}))
-1279
```

Linearly dependent rows are removed:

```
>> LatticeReduce({{1,2},{2,4}})
{{1,2}}
```
