## ToNumberField

```
ToNumberField(a, theta)
```

> expresses the algebraic number `a` as an `AlgebraicNumber` object of the field generated by `theta`.

```
ToNumberField({a1, a2, ...}, theta)
```

> expresses each `ai` in the field generated by `theta`.

```
ToNumberField({a1, a2, ...})
ToNumberField({a1, a2, ...}, All)
```

> expresses all `ai` in one field which contains them, generated by a single element.

```
ToNumberField(a)
```

> writes the algebraic number `a` as an `AlgebraicNumber` object of the field it generates.

It stays unevaluated when a number is not in the given field.

See
* [Wikipedia - Primitive element theorem](https://en.wikipedia.org/wiki/Primitive_element_theorem)

### Examples

```
>> ToNumberField(Sqrt(2),2^(1/4))
AlgebraicNumber(Root(-2+#1^4&,2,0),{0,0,1,0})

>> ToNumberField(1/(1+Sqrt(3)),Sqrt(3))
AlgebraicNumber(Sqrt(3),{-1/2,1/2})

>> ToNumberField(Sqrt(3),Sqrt(2))
ToNumberField(Sqrt(3),Sqrt(2))

>> ToNumberField({Sqrt(2),I},All)[[1,1]]
Root(9-2*#1^2+#1^4&,4,0)
```
