## NumberMultiplier

```
NumberMultiplier -> "str"
```

> is an option of the number form wrappers which sets the string between the mantissa and the power of `10` in scientific notation.

The default is `NumberMultiplier -> "×"`.

### Examples

```
>> ScientificForm(2.5*^7, NumberMultiplier -> " ")
2.5 10^7
```
